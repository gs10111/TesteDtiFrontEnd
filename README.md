# Sistema de Notas Escolar

## 📌 Sobre o Projeto
O **Sistema de Notas Escolar** é uma aplicação full stack desenvolvida em **.NET** para o backend e **React** para o frontend.
## 🚀 Tecnologias Utilizadas

### Backend:
- **.NET** (versão utilizada no projeto)
- **MongoDB** para armazenamento de dados
- **MongoDB.Driver** para comunicação com o banco de dados
- **ASP.NET Core** para a API
- **Swagger** para documentação da API

### Frontend:
- **React** 
- **React Router** para navegação entre páginas
- **Material-UI** para estilização 

## ⚙️ Funcionalidades
- 📌 Cadastro de alunos
- 📌 Registro de notas dos alunos
- 📌 Consulta de notas e médias

## 🎯 Como Executar o Projeto

### Pré-requisitos
Antes de executar o projeto, certifique-se de ter instalado:
- **Node.js** e **npm** 
 - **Visual Studio Code** 

### Backend (API)
1. Clone o repositório:
   ```bash
   git clone https://github.com/seu-usuario/sistema-de-notas.git](https://github.com/gs10111/TesteDtiFrontEnd.git
   ```
2. Acesse a pasta do frontEnd:
   ```bash
   cd sistema-notas-frequencia-front
   ```
3. Restaure as dependências:
   ```bash
   npm i
   ```
4. Inicie o frontend:
   ```bash
   npm start
   ```

   ```

O frontend estará disponível em `http://localhost:3000` (ou outra porta configurada).
